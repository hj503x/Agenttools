AgentTools.dev

Small, reliable utility APIs built for AI agents. No SDK, no auth for now — just POST JSON and get JSON back.

4 endpoints live · more added weekly

POST /sandbox

Run a short JS snippet safely with a 2s timeout. Good for data transforms, calculations, quick parsing.

curl -X POST https://api.agenttools.dev/sandbox \
  -H "Content-Type: application/json" \
  -d '{"code": "return input.a + input.b;", "input": {"a": 2, "b": 3}}'

→ { "result": 5, "logs": [], "timeMs": 1 }

POST /clean-html

Strip nav, ads, scripts, and boilerplate. Returns title + main readable text.

curl -X POST https://api.agenttools.dev/clean-html \
  -H "Content-Type: application/json" \
  -d '{"html": "<html>...</html>"}'

→ { "title": "...", "content": "...", "wordCount": 812 }

POST /extract-table

Parses every <table> in a page into clean row/column JSON.

curl -X POST https://api.agenttools.dev/extract-table \
  -H "Content-Type: application/json" \
  -d '{"html": "<table>...</table>"}'

→ { "tableCount": 1, "tables": [[["Name","Age"],["Sam","29"]]] }

POST /split-text

Paragraph-aware chunking for RAG pipelines. Keeps chunks under a token budget without cutting mid-sentence where avoidable.

curl -X POST https://api.agenttools.dev/split-text \
  -H "Content-Type: application/json" \
  -d '{"text": "long document...", "maxTokens": 500}'

→ { "chunkCount": 3, "chunks": [...] }
